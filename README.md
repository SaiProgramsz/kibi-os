<h1>Kibi OS</h1>

Kibi OS is an operating system based on Debian GNU/Linux <br>
designed to run natively on microSD Cards / USB Drives. It keeps the <br>
essentials and cuts the crap to make your computer faster and <br>
more reliable. It benefits from Debian's stability and vast <br>
software collection.

<h3>Why microSD Cards/USBs and not HDDs and SSDs?</h3>

If Kibi OS runs smoothly with sufficient space for actual <br>
work on my 10-year-old 4 GB microSD Card, it will definitely run smooth <br>
everywhere 💀
